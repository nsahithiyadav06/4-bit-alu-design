# 4-bit-alu-design
This project implements a 4-bit Arithmetic Logic Unit using Verilog HDL

## Operations Supported
- Addition
- Subtraction
- AND
- OR
- XOR

## Tools Used
- Xilinx Vivado
- Verilog HDL

## Features
- 4-bit output
- 3-bit select line
- Multiple arithmetic and logical operations
